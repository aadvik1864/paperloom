# Paperloom

Paperloom is an academic publishing website where researchers can share papers,
read ideas from the community, and explore work across disciplines.

## Features

- Search, filter, and sort research papers by topic and relevance.
- Read paper details, preview or download PDFs, copy citations, and save bookmarks.
- Publish and read research blog posts, with comments and author profiles.
- Give authors tools to publish work and follow its readership.
- Provide administrators with tools to manage accounts and moderate publications.
- Browse a responsive interface with light and dark themes.
