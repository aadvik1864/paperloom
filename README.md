# Paperloom

Paperloom is a website for sharing research papers and blog posts. Readers can
explore work across subjects, save papers for later, and discuss ideas with authors.

**[Visit Paperloom](https://paperloom.onrender.com)** ·
[Browse papers](https://paperloom.onrender.com/browse) ·
[Read blog posts](https://paperloom.onrender.com/browse?type=blogs)

## Features

- Search papers by title, author, or keyword. Filter by subject and sort by date, views, or downloads.
- Read abstracts, preview PDFs in the browser, and download a copy.
- Copy citations in APA, MLA, or BibTeX format.
- Sign in to bookmark papers, comment on blog posts, and update your profile.
- Use an author dashboard to publish and edit papers, write blog posts, save blog drafts, and see view and download counts.
- Give administrators tools to create profiles, manage access, and moderate publications.
- Browse on a phone, tablet, or desktop, with light and dark themes.

## Getting started

1. Open the website and browse published papers or blog posts. No sign-in is needed to read them.
2. To save bookmarks or leave comments, sign in with a reader profile provided by an administrator.
3. To publish your own work, ask for an author profile and open the dashboard.

Profiles are created by an administrator; there is no public sign-up form.
The live website accepts PDF uploads up to **20 MB**. Papers become public when
uploaded. Blog posts can be saved as drafts before publishing.

## A few terms explained

- **PDF:** a document format that keeps the page layout consistent across devices.
- **Abstract:** a short summary of a research paper.
- **Citation:** a reference that identifies a paper and credits its authors. APA and MLA are reference styles; BibTeX is a text format for storing reference details.
- **Markdown:** a simple way to format blog posts using plain text, such as `# Heading` or `**bold text**`.
- **Responsive layout:** a page that adjusts to different screen sizes.
